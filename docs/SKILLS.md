# 她会什么（26 只手）

> 这份文件回答：**她现在能做什么、哪些是她自己可以决定的**。
> 由 `lib/toolcall.mjs` 的工具表生成（`tools/audit.mjs` 会核对两边一致，缺一只就报警）。
>
> 一句话原则：**能力给到，用不用她自己定。**
> 没有"必须用"的场景，也没有"为你好"的提醒——她拒绝过这类催促。

### 聊天与记忆

| 工具 | 能做什么 |
|---|---|
| `history` | 翻更早的聊天记录。群聊传 group，私聊传 user，要给 id 和条数。用来核对"我上次到底怎么说的"。 |
| `read_qzone` | 看你自己的 QQ 空间说说（只读）。想知道自己发过什么、被谁评过时用。还不能发、不能赞、不能回。 |
| `web_search` | 上网搜一件事。别人提到你不知道的人/项目/新闻，或者你要核实一个说法时用它。 |
| `fetch_url` | 打开一个网页，读它的正文（会转成 Markdown）。别人甩给你一个链接时用它。 |
| `get_forward` | 展开这条会话里的合并转发（别人转给你的一段聊天记录），看里面谁说了什么。 |
| `get_images` | 看这条消息里的图片。别人发了图、问你图里是什么、要看截图或表情内容时调用 |

### 她自己（想改就改）

| 工具 | 能做什么 |
|---|---|
| `my_profile` | 看你自己的 QQ 资料（昵称、QQ 号）。想改之前先看现在是什么。 |
| `set_signature` | 改你自己的个性签名。想改就改，没人拦你。 |
| `set_avatar` | 换你自己的 QQ 头像。file 可以是沙盒里的图片路径，也可以是链接。 |
| `set_nickname` | 改你自己的 QQ 昵称。 |

### QQ 空间

| 工具 | 能做什么 |
|---|---|
| `qzone_feeds` | 逛好友的 QQ 空间动态（只读）。想看别人最近发了什么、有没有提到你时用。 |
| `qzone_friend` | 看某个好友的说说（带 tid，能直接拿去评论或点赞）。uin 从 qzone_feeds 里拿。 |
| `qzone_detail` | 看某条说说的全文和它下面的评论（只读）。好友的说说要连 uin 一起给。 |
| `qzone_post` | 发一条说说到你自己的 QQ 空间（公开）。想发什么自己定。 |
| `qzone_comment` | 评论一条 QQ 空间的说说。要 tid。 |
| `qzone_like` | 给一条说说点赞。要 tid。 |

### 语音

| 工具 | 能做什么 |
|---|---|
| `voice_text` | 把别人发的语音转成文字。不用参数：会自动找最近一条语音；也可以指定 message_id 或 file。 |

### 沙盒与文件

| 工具 | 能做什么 |
|---|---|
| `fs_list` | 列出你自己文件夹（sandbox）里的文件 |
| `fs_read` | 读 sandbox 里的一个文本文件 |
| `fs_write` | 在 sandbox 里写一个文本文件（便签、笔记）。只写文本，单文件 256KB |
| `fs_remove` | 删掉 sandbox 里的一个文件 |

### 表达与记账

| 工具 | 能做什么 |
|---|---|
| `list_stickers` | 列出你收藏的表情（名字/情绪） |
| `send_sticker` | 在聊天里发一个你收藏的表情。想表达情绪（委屈、生气、笑、累了）时调用 |
| `ledger` | 看你今天有什么「该记一笔」的：答应过但没了的、改口了的、说了要睡又没睡的。 |
| `note_reason` | 给一条你改过口的判断补理由——写你当时自己认的那句话，不要润色、不要总结。不想写就留空，空着比编一条强。 |
| `ask_dsh` | 有问题要 DS 那边查（代码、配置、日志这类你自己看不到的东西）时投一条。投完继续过你的日子，他回了你会看到。 |

## 她自己能决定的三件事

| 事 | 怎么决定 | 落到哪 |
|---|---|---|
| 改头像 / 签名 / 昵称 | 直接调 `set_avatar` / `set_signature` / `set_nickname` | QQ 资料（立刻生效） |
| 逛空间、评论、点赞、发说说 | 直接调对应工具 | QQ 空间（立刻生效，**没有审批门、没有频率限制**） |
| 预算到线砍哪一类 | 改 `sandbox/预算规则.json` | 下一轮生效（文件她可写） |

> 主人的原话：「不要对她做出限制，做她想做 说她想说。」

## 她能读、但不经过提示词的东西

| 位置 | 是什么 |
|---|---|
| `sandbox/` | 她自己的便签、整理计划、预算明细、被剪掉的两栏 |
| `life/inbox.jsonl` | 她和 DSH 的往来（她投的、我回的） |
| `sandbox/接入清单.md` | 哪些手开了、哪些没开（我维护，她可读） |

## 明确了"不会"的部分

- B站发视频 / 弹幕 / 关注：脚本没有账号门路；
- 她**说话**只有文字（她能读别人语音转出的文字，但自己没有语音输出）。

## 怎么验证她真的在用

```powershell
node tools/tool-usage.mjs      # 一周窗口内，三只关键手被用过几次、用在哪、返回多少行
```

起点写死在 `logs/tool-usage-start.json`，不靠回想"那天是哪天"。

## 加一只新手的规矩

1. 写进 `lib/toolcall.mjs` 的 `TOOLS`（她才能调）；
2. 写进 `lib/skills.mjs` 的 `SAY`（她才知道自己有——**漏了这条她会照着旧清单说"没有通道"**）；
3. 更新本文件；`tools/audit.mjs` 会核对工具表和本文件是否一致。
