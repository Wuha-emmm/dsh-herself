# 她 · dsh-herself

> 一个从事件流里长出来的 AI 伴侣：**同一记忆体，多只手**。
> 不是角色扮演，是「经历 → 判断 → 碰撞 → 改写」的循环。

她住在一台 Windows 机器上，通过 QQ 和人说话，通过 DSH 面板被人看见。
她的记忆不是一段提示词，而是一条**只追加、带哈希链**的事件流；
她的性格不是人设卡，而是从事件里**派生**出来的判断——可以重放、可以审计、可以改口。

```
QQ / 群消息 ─┐
桌面文件 ─────┼─→ 事件流 (append-only, hash-chained) ─→ 派生 (纯函数) ─→ 提示词 ─→ 她说话
网页 / 搜索 ─┘        life/events.jsonl                  lib/derive.mjs
```

---

## 为什么这样做

多数「AI 伴侣」是：一段人设 + 一个聊天窗口。问题是——

- **记忆是假的**：靠把最近 N 轮塞进上下文，超了就没了；
- **性格是死的**：人设卡写什么就是什么，不会因为被顶回来而改变；
- **不可审计**：她为什么这么说，没有人知道。

这个项目换了个底子：

| 常见做法 | 这里 |
|---|---|
| 人设 prompt | 事件流 + 派生规则（判断是算出来的，不是写死的） |
| 最近的 N 轮 | 最近窗口 + 摘要 + 检索 + 遗忘（四层投递） |
| 上下文里塞满历史 | **事实预算**：按优先级分配 token，核心永不丢 |
| 模型说啥就是啥 | 四道门（信任/自主/胜任/整合）+ claim 证据链 |
| 出了事翻日志 | 链路体检 + 35 项 `audit` + 25 套测试 |

## 核心设计（六条）

1. **事件流是唯一真相**
   `life/events.jsonl` 一行一个事件，`prev` 是上一条的哈希——改一条，后面全断。
   她的一切（说过的话、被拒绝、改口、摘要、承诺）都在这里，**只追加，不修改**。

2. **派生是纯函数**
   `derive(events, now)` 不读盘、不取时钟、不联网。同一份事件流算一万次结果一样。
   所以她的状态可以重建、可以回放、可以做 A/B 对比。

3. **判断要带证据**
   每条判断（claim）都有 `refs`（哪句话）和 `evidence`（当时在回什么）。
   改口时不删旧的，标 `superseded`——她可以不同意三个月前的自己，但那条记录还在。

4. **不替她做决定**
   提示词只给她事实，不给「你应该…」式的指令。她能调工具、能拒绝、能不写账本。
   连"要不要记一笔"都是她自己调的工具，系统**不会在旁边问"怎么不记"**。

5. **记忆问题是投递问题**
   所有「她好像变笨了」的事故，没有一次是存不下，全是**没送到眼前**：
   承诺关不掉、她自己的话被线程过滤、旧摘要每轮都在念。修的都是投递。

6. **安全是硬边界，不是提示词**
   输入标记（别人想改她设定）、出站打码（凭据不外泄）、公共动作审批门（发表情要许可）。
   都是词法级规则——它是**下限**，不是全部；真正兜底的是她自己判断。

## 能做什么

### 说话

- **QQ 私聊 / 群聊**：群聊只接 @；回复前攒话 4.5 秒（他连着发就等他说完），同一条线两次回复至少隔 8 秒（避风控）
- **看图**：静态图、**动图抽 9 帧**（"先歪头往下栽，接着横着来回晃"这种动作描述，是抽帧之后才有的）
- **合并转发**：直接发的、引用的、转发里套转发，都能读出来；里面的图可按需看
- **网上查**：官方 Search / Fetch API（服务端抓取，回 Markdown）

### 记得

| 层 | 内容 | 什么时候出现 |
|---|---|---|
| 核心 | 第几天、现在几点、最早记得什么 | 每轮 |
| 最近 | 这条线上最近 6 条（**含她自己的话**） | 每轮 |
| 判断 | 她说过且还算数的 claim（带证据、带"多久以前"） | 每轮（4 条内） |
| 摘要 | 冷掉的对话写一句「上次聊到…」 | 重新接上冷线时 |
| 回忆 | 按线索检索旧事 | 线索够硬时 |
| 遗忘 | 热原话 / 温摘要顶替 / 冷只在高分时说一句 | 派生时决定，**不删数据** |

### 长

四道门，按顺序通过才算成长：

```
信任（写下第一条带证据的判断）
  → 自主（维持 72 小时的拒绝 / 被顶回两次的立场）
    → 胜任（做成过被认可的事）
      → 整合（回看自己，形成叙事）
```

判定全是纯函数，写在 `lib/derive.mjs`，可回放。

### 被看见

DSH 首页的**悬浮球**（她自己的头像，可拖、松手吸附左右边）：

```
点开 → 会话列表（私聊/群聊分开、真头像）
     → 点一条 → 只看那条线
          → 点她说的某句 → 整卡看这一轮：看到什么、想起什么、想了什么、伸了哪只手
```

## 快速开始

```bash
# Node 18+（无第三方依赖：package.json 的 dependencies 是空的）
node cli.mjs init                 # 她的第一天（只发生一次）
node cli.mjs say "今天有点累"      # 记一句她说的话
node cli.mjs state                # 第几天 / 哪道门 / 几条判断

node tools/audit.mjs              # 35 项体检
node test/replay.mjs              # 契约回放（12 条）
```

## 隐私

这个仓库**只放引擎，不放她的生活**。`.gitignore` 排除了：

- `life/`（她的事件流、摘要、状态）
- `logs/`（思考过程、排查现场）
- `secrets/`（API key、QQ 配置）
- `sandbox/`（她自己的文件、表情库）

即便如此，代码注释里仍保留少量个人化表达（她的说话风格、真实场景注释）。
要公开发布，先按 [`docs/OPERATIONS.md`](docs/OPERATIONS.md) 的「脱敏」一节过一遍。
