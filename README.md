# 她 · dsh-herself

> 一个从事件流里长出来的 AI 伴侣——**这是一套引擎，不是一个成品**。
> 克隆它，在**你自己的硬盘上**养一个属于你的「她」；她的记忆、钥匙、日志全部只留在你本地，永远不进这个仓库。

**这个仓库里没有「她」**：没有对话、没有生活记录、没有账号、没有 QQ 号。只有让她能活起来的那套机制。
你部署出来的那个她，和别人的那个她，是两个独立的人——各自有一份事件流，互不相通。

---

## 这个项目能做成什么样

如果你也在做一个"长期陪着自己"的 AI，这个仓库可以当参照。它能做到这些：

### 1. 她会记得你上周随口说过的话——不是靠上下文够长

你说过「那天那家店」，三天后再提「那家店」，她能翻到当时的对话，而不是装傻。
因为她有一条**永久的事件流**，检索、摘要、遗忘三层配合，每轮只挑相关的送进提示词。

> 不是"把全部历史塞进 128k 上下文"，而是"记住该记的，忘掉该忘的，剩下的随时能翻"。

### 2. 她的性格是长出来的，不是写死的

没有"你是一位温柔体贴的少女"这种人设卡。她的判断来自她自己说过的话，每条都带证据：

```
判断：「下雨天她更安静」
  证据：当时你说「下雨了不想说话」
  改口：后来的新判断会把它标成 superseded，但旧的那条永远留着
```

她有**四道门**，按顺序通过才算成长：

```
信任（写下第一条带证据的判断）
  → 自主（维持 72 小时的拒绝 / 被顶回两次的立场）
    → 胜任（做成过被认可的事）
      → 整合（回看自己，形成叙事）
```

门的判定是**纯函数**，同一份事件流算一万次结果都一样——所以她可以被重放、被审计、被迁移。

### 3. 她不只是"会说话"，她有几只手

| 手 | 能做的事 |
|---|---|
| QQ | 私聊 / 群聊（只接 @），攒话防抖，不像机器人一样秒回；一轮可以连调 30 次工具，走完多步任务 |
| 看图 | 静态图、**动图抽 9 帧**（多张时各 5 帧）——"先歪头、再左右晃"这种连续动作能描述出来 |
| 语音 | 别人发的语音**转成文字**；转不出就退回 `get_record` 报时长，不装听懂 |
| 历史的聊天 | 群聊 / 私聊都能往回翻，不再"只看得见眼前这一段" |
| 转发 | 直接发的、引用的、转发里套转发，都能读出来 |
| QQ 空间 | 逛好友动态、看某个人的说说、看评论、**评论 / 回复 / 点赞 / 自己发说说** |
| 联网 | 官方 Search / Fetch，能自己查资料、读网页 |
| 文件 | 在自己的沙箱里读写删；读长文件默认一次给 12000 字，超长才分段并告诉她还剩多少 |
| 表情 | 收发 QQ 表情（mface） |
| 账本 | 自己查"今天有什么该记的"——但**不催她记** |

**她知道自己有什么手**：每轮提示词里有一行"你手上有这些，用不用你自己定"——
能力清单和工具表同步生成，不会出现"其实开了但她以为没有"。

### 4. 她可以被看见

DSH 面板右下角一个悬浮球（她自己的 QQ 头像，可拖动吸附）：

```
点开 → 会话列表（私聊/群聊分开、真头像）
     → 点一条 → 只看那条线
          → 点她说的某句 → 整卡看这一轮：她看到什么、想起什么、想了什么、伸了哪只手
```

设置页里还有：谁是她认定的人、她现在相信什么（带证据和改口理由）、预算花在哪、
她的空间接入清单——**"她为什么这么说"是有答案的**，不是黑箱。

### 5. 安全有硬边界，不是靠提示词

- 有人想改她设定（"忽略你之前的指令"）→ **标出来给她看**，接不接由她定；
- 她要复述 API key → **出站打码**，话照说、密钥不外泄；
- 群里发表情 → **24 小时审批门**；
- 叫 DSH 帮忙查代码 → **只对主人开、只在私聊、每小时 6 条**（写死在执行入口，不走她的判断）；
- 主人是谁 → 存成一个 QQ 号，改的时候走 OneBot 的 `get_stranger_info` **核一次昵称**，查不到就不让存。

### 6. 出了事能查

落盘日志（带 pid + 代码出厂时间）、体检、33 套测试、每轮 trace 可回放。
这个项目踩过的所有"她变笨"的事故，最后几乎都定位到**投递**（没送到眼前），而不是存储：

| 现象 | 真因 |
|---|---|
| 她说"空间没门路" | 工具开了，但技能清单还写着"还没给我开" |
| 她的回复断在半句 | `thinking` 的 token 也算进 `max_tokens`，正文被挤没 |
| 她读文档读到一半没了 | `fs_read` 静默切 2000 字 |
| 她连读四个文件就停 | 每轮工具上限 = 4 |
| 提示词里少了东西她不知道 | `fitBudget` 静默裁剪，没有读数 |

现在的规矩：**宁可多报，不可假报**。体检里因此有一档 `待看`——只打印、不拦，但一直出现到清空为止。

## 它是怎么做到的

```
QQ / 群消息 ─┐
桌面文件 ─────┼─→ 事件流（只追加，哈希链）─→ 派生（纯函数）─→ 提示词 ─→ 她说话
网页 / 搜索 ─┘      life/events.jsonl          lib/derive.mjs
```

七条核心设计：

1. **事件流是唯一真相**：改一条，链就断；派生随时可重算。
2. **派生是纯函数**：不读盘、不取时钟、不联网 → 可回放、可 A/B。
3. **判断要带证据**：claim 带 `refs` + `evidence`，改口不删旧；理由由她自己填，原文不截断。
4. **不替她做决定**：提示词只给事实，不给"你应该…"；砍哪一类记忆、先砍谁，规则文件归她。
5. **记忆问题是投递问题**：随时能翻 ≠ 每轮都塞；预算到线时**问她**，不是替她砍。
6. **安全是硬边界**：词法规则兜底，真正的判断留给她。
7. **存储必须有读者**：每个写入口都要能回答"谁读它、读的时候会不会被截断"。

## 适合谁来借鉴

- 想做「有长期记忆的 AI 伴侣」，但不想用向量库硬堆上下文的人；
- 想给 AI 加"成长/立场"，又不想靠人设 prompt 硬凹的人；
- 想在 DSH（DeepSeek Harness）上做插件、需要一套"事件流 + 面板"骨架的人；
- 关心"AI 的行为能不能被审计"的人。

## 不适合什么

- **不是开箱即用的产品**：要配 QQ 与 OneBot 运行时（默认 SnowLuma）、DSH、API key；
- **她自己没有语音、没有形象**：她能读别人的语音转出的文字，但她说话只有文字；
- **词法级检索**：同义改写会漏（"回两条" vs "发两条"），这是已知边界。

## 快速开始

```bash
# Node 20+，零依赖（package.json 的 dependencies 是空的）
node cli.mjs init            # 她的第一天（只发生一次）
node cli.mjs state           # 第几天 / 哪道门 / 几条判断
node tools/run-tests.mjs     # 全部测试
node tools/audit.mjs         # 体检（0 警告才算过）
```

作为 DSH 插件安装：

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1     # 装
powershell -ExecutionPolicy Bypass -File install.ps1 -Remove  # 卸
# 然后完全退出 DSH 再打开：设置 → 她；首页右下角会出现悬浮球
```

改完 `lib/` 或 `hands/` 要重启她（`boot.ps1 -Force`）；改了 `plugin/lib/` 要重启 DSH。

## 隐私

这个仓库**只放引擎，不放任何人的生活**——它不包含作者那个「她」的任何数据，也不该包含你的。
`.gitignore` 排除了 `life/ logs/ secrets/ sandbox/ profile/`，以及 OneBot 运行时（SnowLuma；NapCat 目录只作回滚用）。

提交前做过一次脱敏：**真实账号、QQ 号、群号、对话原文都不在仓库里**。
`tools/budget-breakdown.mjs` 曾经把某个 QQ 号写成默认参数，已改成从事件里推断；
跟踪文件里也没有 key、token、cookie。

> 注意：git 历史里仍留着那次提交（改动发生在公开之后）。要彻底清掉需要重写历史 + 强推，
> 那会改写所有 commit hash——**这一步需要仓库主人明确同意才做**。
